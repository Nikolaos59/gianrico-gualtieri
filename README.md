# Gianrico Gualtieri

Portfolio statique multilingue de Gianrico Gualtieri.

- Français : `index.html` et `pages/`
- Allemand : `de/`
- Anglais : `en/`
- Italien : `it/`
- Néerlandais : `nl/`

Chaque version présente l’accueil, l’artiste, la peinture ancienne, une galerie et le contact. Les photographies et illustrations sont dans `assets/images/`. Le site est publié sur Cloudflare Workers ; `robots.txt` et `sitemap.xml` sont à la racine.
